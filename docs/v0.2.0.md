# v0.2.0 路线图

## 目标

1. **真实模型可验证**:有 API key 时跑通全部流程(目前仅 mock 验证),补 key 模式的冒烟脚本。
2. **云端风格库可用**:Postgres 模式端到端验证(含 e2e,需 `DATABASE_URL`),版本历史 / 回滚 / diff 走真实库。
3. **小红书抓取稳定**:真实 cookie 抓取(`pnpm test:xhs`)的成功率与错误提示。
4. **发布准备**:Docker 镜像发布、`RELEASE.md` 流程固化。

## 范围

- 新增 CI job:带 Postgres service 的集成测试 / e2e。
- 风格评分(judge)权重可配置前先收集真实样本评估。
- 依赖由 Dependabot 每周更新,按周合并。

## 不做

- LangGraph / 多 agent 编排。
- 账号体系、多用户、权限。
- 自动发布到各平台(仅生成与复制)。
- 新增图像 / 视频生成。

## 迁移步骤(v0.1 → v0.2)

1. 本地风格无需迁移:仍在 localStorage,云端模式下「上传到云端」手动同步。
2. 启用云端:设置 `DATABASE_URL` → `pnpm db:push`。
3. 启用真实模型:设置 `ANTHROPIC_API_KEY`,`/api/health` 的 `mode` 应为 `anthropic`。
4. API 向后兼容:v0.2 不删除 v0.1 的 15 个 API 路由与字段,仅新增。
