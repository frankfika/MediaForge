# Product Spec / 产品规格

## 1. 用户与场景

独立内容创作者,同一素材要发 4 个平台,且希望"像自己写的"。三条主线:

1. **改写**:看到好内容 → 贴链接 → 拿到各平台版本(图/视频保留)→ 复制发布
2. **创作**:有话题 → AI 按我的文风写 → 适配各平台
3. **调教**:不像我 → 一句话纠正,或者我直接改稿,AI 从我的修改里学

成功指标:链接 → 复制 ≤ 3 次点击/≤ 30 秒;复制率(`outputs.copiedAt` 非空)> 60%;风格修正 ≤ 2 轮满意。

## 2. 信息架构

```
/          对话(默认,含完整闭环)        导航:对话 · 改写 · 创作 · 风格   [风格选择器 ▾]
/rewrite   改写(表单化入口,同一后端)
/editor    创作(话题→流式初稿→适配平台→从手改学习)
/styles    风格管理(学习、修正、使用、删除)
```

全局状态只有一个:**当前风格**(导航右上角,任何页面可切)。

## 4. 关键交互流

| 流       | 步骤                                                                                           | 失败处理                             |
| -------- | ---------------------------------------------------------------------------------------------- | ------------------------------------ |
| 链接改写 | 贴链接 → `fetch_link`(状态行"正在抓取…")→ 来源卡片 → 追问/推断平台 → `rewrite_post` → Tab+复制 | 工具失败:行内错误 + 建议"直接贴正文" |
| 创作     | brief → 流式初稿(可随时编辑)→ 适配                                                             | 参考链接抓取失败静默跳过             |
| 风格学习 | 贴样本 → 等待(10–30s)→ 新风格自动设为当前                                                      | <1 个样本禁用按钮;样本过短提示       |
| 风格修正 | 一句话反馈 → 新版本 + 变更摘要;或在创作页改稿 → "从修改中学习"                                 | 版本可回滚(Phase 2)                  |

## 5. 交互细则 (UX)

- 回车发送,Shift+回车换行;**输入法组字中不触发发送**(`isComposing`)
- 任何等待 >300ms 必有状态文案,绝不出现无反馈的空白
- 复制成功:按钮变 ✓ "已复制" 1.5s,不弹 toast
- 字数实时显示 `当前/平台上限`,超限变红(Phase 2)
- 全键盘可达;焦点环统一 accent 色;`prefers-reduced-motion` 关闭动画
- 移动端:单列;输入框吸底

## 6. Roadmap

P1 登录 + Postgres 持久化 / 历史记录 · P2 公众号内联 HTML 复制 + ZIP 导出 · P3 全局 ⌘K 对话抽屉(任意页面唤起,自带页面上下文)· P4 风格自动评测与回滚 · P5 小红书登录态抓取(Firecrawl)· P6 发布前预览(仿各平台排版)
